# Wharf 0.1.0 implementation plan

Research source:
`.copilot-tracking/2026-10-06-wharf-0.1.0-research.md`

## 1. Establish the Go module and validation boundary

Targets:

- `go.mod`
- `go.sum`
- `scripts/validate-wharf.sh`
- `README.md`

Tasks:

- [x] Initialize module `github.com/bartr/wharf` with Go 1.27.
- [x] Add and pin Cobra.
- [x] Add one executable validation script that runs `gofmt`, `go vet`,
      `go test`, and a clean Wharf build without leaving a binary in the tree.
- [x] Document Go 1.27 and the validation command in the root README.

Exit criteria:

- `go env GOMOD` resolves to the root `go.mod`.
- The dependency graph contains Cobra and no Viper dependency.
- The validation command is documented and executable.

## 2. Add version and exit contracts

Targets:

- `internal/version/version.go`
- `internal/version/version_test.go`
- `internal/exitcode/exitcode.go`
- `internal/exitcode/exitcode_test.go`

Tasks:

- [x] Define the sole `Version = "0.1.0"` variable.
- [x] Define typed error categories and constants for success, internal,
      invalid input, unsupported host, blocked run, and partial run.
- [x] Map wrapped typed errors and untyped failures deterministically.

Exit criteria:

- Source search finds exactly one `Version` variable declaration.
- Unit tests prove every exit category and wrapped-error behavior.

## 3. Implement typed global configuration

Targets:

- `internal/config/config.go`
- `internal/config/config_test.go`

Tasks:

- [x] Define typed console format, quiet, and verbosity settings.
- [x] Define exported constants for `WHARF_LOG_FORMAT`, `WHARF_QUIET`, and
      `WHARF_VERBOSE`.
- [x] Parse an injected environment lookup explicitly and reject invalid
      format, boolean, integer, and out-of-range verbosity values.
- [x] Merge only changed flags over environment over defaults.

Exit criteria:

- Table tests prove defaults, environment handling, flag precedence, and all
  invalid values.
- No implicit environment binding or global process-environment mutation is
  needed in tests.

## 4. Implement logging and redaction foundations

Targets:

- `internal/logging/logging.go`
- `internal/logging/console_handler.go`
- `internal/logging/logging_test.go`

Tasks:

- [x] Define a Wharf-owned logger interface and typed public/secret attributes.
- [x] Define verbosity levels with distinct thresholds for default, `-v`,
      `-vv`, and `-vvv`.
- [x] Implement a tab-delimited human console handler.
- [x] Implement optional JSON console rendering and an independent,
      always-JSON durable sink with a schema-version attribute.
- [x] Apply an injectable redaction hook before both sinks.
- [x] Ensure quiet mode suppresses nonessential console records but never the
      durable sink.

Exit criteria:

- Tests prove valid tab-delimited and line-delimited JSON output.
- Tests prove all four verbosity thresholds are distinct.
- A synthetic credential is absent from both outputs.
- Quiet mode produces no nonessential console line and still emits durable JSON.

## 5. Build the reusable Cobra command tree

Targets:

- `internal/command/root.go`
- `internal/command/completion.go`
- `internal/command/operational.go`
- `internal/command/root_test.go`
- `internal/command/testdata/root_help.golden`
- `internal/command/testdata/check_help.golden`

Tasks:

- [x] Construct fresh commands through dependency-injected constructors.
- [x] Register `check`, `smoke`, `run`, `resume`, `status`, `stop`, `report`,
      `completion`, and `version`.
- [x] Add persistent `--quiet`, `--log-format`, and count-based
      `--verbose`/`-v` flags.
- [x] Resolve changed flags over the injected environment before command
      execution.
- [x] Implement semver-only `version` and `--version`.
- [x] Generate Bash and Zsh completion and reject unsupported shells.
- [x] Return explicit typed not-implemented failures from all operational
      commands.
- [x] Disable Cobra's automatic error/usage printing so the process boundary
      owns failures.

Exit criteria:

- Command-registration tests see the exact required command set.
- Golden tests cover root and `check` help.
- Version output is exactly one semver line.
- `-v`, `-vv`, and `-vvv` produce configuration levels 1, 2, and 3.
- Unknown commands, unknown flags, and unsupported completion shells are
  invalid input.
- Every operational command fails and none simulate success.

## 6. Add the thin process boundary and integration proof

Targets:

- `cmd/wharf/main.go`
- `cmd/wharf/main_test.go`

Tasks:

- [x] Keep `main` limited to dependency wiring, execution, one error print, and
      `os.Exit`.
- [x] Build and execute Wharf in tests to prove default version output.
- [x] Build with
      `-X github.com/bartr/wharf/internal/version.Version=<semver>` and prove
      injected output.
- [x] Prove unknown commands and flags return exit code 2.
- [x] Prove an operational command returns a nonzero internal-failure code.
- [x] Prove Bash and Zsh completion generation succeeds through the binary.

Exit criteria:

- The integration tests exercise the actual compiled executable.
- The linker override changes both `wharf version` and `wharf --version`.
- Stdout/stderr and exit statuses match the CLI contract.
