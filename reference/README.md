# DeepSWE v1.1 published cost reference — `claude-opus-5 [max]`

External reference data pulled from the public DeepSWE leaderboard, used to contextualize our
`pier` + Copilot CLI benchmarking.

Methodology and infrastructure notes from the Muse Spark 1.2 paper and related links are tracked in:

- **`muse_spark_methodology_notes.md`** — one-paragraph interpretation note plus captured excerpts and source links.
- **`github_copilot_agentic_harness_methodology.md`** — GitHub's current
  harness-evaluation terminology, controlled-comparison principles, and the
  distinction between independent runs and DeepSWE trials/rollouts.

## Files
- **`deepswe_v1_1_opus5_max_costs.json`** — source of truth. Per-trial **cost (USD)** and per-trial
  **outcome** (`P`=PASS/`F`=FAIL/`E`=ERROR) for every task, keyed by task id (outcome list aligned to
  the cost list). Includes `_meta` with provenance.
- **`deepswe_v1_1_opus5_max_summary.csv`** — per-task aggregates generated from the JSON
  (`task, language, n_trials, n_pass, pass_rate, difficulty, mean_usd, cost_4trials_usd`).
  `language` is joined from `../tasks/manifest.json`; `difficulty` buckets pass rate
  (unsolved=0, hard=0<pr<0.5, mixed=0.5, reliable=0.5<pr<1, solved=1).
- **`quality_gate_panel.json`** — a pinned, difficulty-stratified 40-task A/B panel (seed=42):
  10 each from go/python/typescript (proportional-stratified by opus-5[max] pass-rate bucket),
  all 5 from rust & javascript. Est. cost (opus-5[max] rates): ~$2,027 single-arm / ~$4,054 two-arm
  (4 trials/arm). See `../hve-summary.md` §9 quality gate.

Dashboard trial exports are also kept here, one row per trial:

- `deepswe_v1_1_opus5_max.tsv`
- `deepswe_v1_1_opus5_xhigh.tsv`
- `deepswe_v1_1_gpt5_6_sol_xhigh.tsv`
- `deepswe_v1_1_gpt5_6_luna_max.tsv`
- `deepswe_v1_1_gpt5_6_terra_max.tsv`

Each TSV has a matching per-task summary generated by:

```bash
python3 scripts/summarize_reference.py
```

The summary files contain task, language, trial count, pass count, pass rate,
difficulty bucket, mean cost, and cost normalized to four trials. These files
are external DeepSWE reference runs, not our Copilot or Claude Code arm data.

Reference-specific implementations live in this directory:

- `fetch_baselines.py` downloads and exports dashboard reference arms.
- `summarize_reference.py` generates per-task CSV summaries from reference TSVs.
- `verify_pass_at_1.py` checks which aggregation reproduces the published PASS@1.

Stable compatibility launchers remain in `scripts/`:

```bash
python3 scripts/fetch_baselines.py
python3 scripts/summarize_reference.py
python3 scripts/verify_pass_at_1.py
```

## Important caveats
- **Costs + outcomes only.** Per-trial step counts are not captured here.
- **Different agent scaffold.** The leaderboard runs **mini-swe-agent**, not Claude Code, on the
  same `claude-opus-5` model. Treat as a **quality/cost reference**, not an apples-to-apples
  comparison with our runs (our Claude Code costs run lower on the tasks we've measured).
- **Source:** https://deepswe.datacurve.ai/data/v1.1/trials?model=claude-opus-5::effort=max
  (fetched 2026-07-28).

## Regenerate the summary CSV / panel
```sh
python3 - <<'PY'
import json, csv
d=json.load(open('reference/deepswe_v1_1_opus5_max_costs.json'))
costs=d['costs_usd']; outc=d['outcomes']
lang={t['task_id']:t.get('language','?') for t in json.load(open('tasks/manifest.json'))['tasks']}
def bucket(pr):
    return 'unsolved' if pr==0 else 'hard' if pr<0.5 else 'mixed' if pr==0.5 else 'reliable' if pr<1 else 'solved'
rows=[]
for t in costs:
    n=len(costs[t]); npass=outc[t].count('P'); pr=npass/n; mean=sum(costs[t])/n
    rows.append([t,lang.get(t,'?'),n,npass,round(pr,3),bucket(pr),round(mean,3),round(mean*4,2)])
rows.sort(key=lambda r:(r[1],r[0]))
with open('reference/deepswe_v1_1_opus5_max_summary.csv','w',newline='') as f:
    w=csv.writer(f)
    w.writerow(['task','language','n_trials','n_pass','pass_rate','difficulty','mean_usd','cost_4trials_usd'])
    w.writerows(rows)
PY
```
The pinned panel in `quality_gate_panel.json` is a proportional-stratified seeded (seed=42) draw from
this data (10 go/py/ts, 5 rust/js); regenerate with the same allocation if the source data changes.
